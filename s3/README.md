# go-base/s3

Thin S3-compatible lifecycle adapter using MinIO Go SDK. `s3.Register("default", s3.Config{Endpoint: endpoint, AccessKey: key, SecretKey: secret, UseTLS: true, HealthBucket: "files"})` registers a client. `s3.From(rt, "default")` returns `*minio.Client`, exposing the SDK's PutObject/GetObject/RemoveObject operations. `HealthBucket` is **required**: Start and Health run a live BucketExists check against it, which is the only way to detect a wrong endpoint or bad credentials at startup. Start fails with `ErrHealthBucketRequired` when it is empty. For local development only, `AllowNoHealthBucket: true` skips the requirement; Health then reports only local state. Close invalidates the provider's handle but cannot revoke SDK handles previously handed to callers.
